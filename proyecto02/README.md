# Proyecto 02: Edición de Sonido y Experiencia Educativa Interactiva

Este repositorio contiene la documentación y el desarrollo completo del proyecto 2 para el **Taller de Interfaces**.

## Descripción del Proyecto

El proyecto **"Ecos en la Oscuridad"** es una experiencia educativa interactiva para la web en la que el sonido funciona como el pilar central de la navegación y la toma de decisiones, consiste en un juego de entrenamiento auditivo enfocado en el reconocimiento temprano de situaciones de peligro y emergencia.

* **Mecánica del juego:** El jugador recorre un laberinto a ciegas donde, en cada etapa, se reproduce un estímulo sonoro específico que representa un riesgo (como una fuga de gas, un cortocircuito, una inundación, una motosierra, un enjambre o una jauría de perros).
* **Interacción y aprendizaje:** Para poder avanzar, el usuario debe escuchar con atención, identificar la fuente del peligro y asociar el audio con su ícono visual correspondiente. El sistema entrega retroalimentación visual y sonora inmediata según la decisión tomada.
* **Objetivo:** Desarrollar la agudeza auditiva, la atención y la capacidad de reacción rápida frente a alertas acústicas del entorno mediante una dinámica lúdica.

## Estructura del Repositorio

* **`juego web interactivo/`** : Contiene la aplicación web principal (`index.html`) y la interfaz visual de la experiencia.
* **`audiojuegointeractivo/`** : Carpeta que almacena los recursos y archivos de audio optimizados (`.mp3`) utilizados para los estímulos de emergencia.

## Tecnologías y Recursos

* **Lenguajes y Entorno:** HTML5, CSS3, JavaScript para la lógica de interacción web.
* **Diseño Sonoro:** Edición, optimización y procesamiento de archivos de audio orientados al feedback interactivo y la experiencia de usuario.
