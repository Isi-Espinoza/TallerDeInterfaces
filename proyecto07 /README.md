# Proyecto 06 | Consola y Sintetizador Interactivo

Este repositorio contiene la documentación y el desarrollo completo del proyecto 6 para el **Taller de Interfaces**.

## Descripción del Proyecto

El proyecto "Consola - V02" es un sistema interactivo físico y digital controlado por voz. Integra una interfaz tangible que combina controles modulares (como botones arcade, un fader deslizante y potenciómetros) con un control dinámico guiado por voz a través de la Web Speech API. 

Permite la lectura bidireccional mediante Web Serial API para modular la intensidad, los colores y las animaciones de un anillo de LEDs NeoPixel, logrando una sincronización fluida en tiempo real entre la consola física y un dashboard digital.

## Estructura del Repositorio

* **`códigosconsola/`** : Archivos de código fuente utilizados para la programación de la consola.
* **`consola web/`** : Interfaz web interactiva para el control de la consola.
* **`modeloconsola/`** : Archivos de modelado digital en Rhino correspondientes al diseño de la consola.
* **`laminadiagrama/`** : Lámina explicativa y esquemáticas con el diagrama de conexiones y componentes.
* **`laminaproyecto/`** : Archivos correspondientes a la lámina general de presentación del proyecto.
* **`fotosproceso/`** : Registro fotográfico ordenado del proceso de armado y pruebas (14 imágenes).

## Tecnologías y Recursos

* **Hardware y Microcontroladores:** Arduino, botones arcade, fader, potenciómetros y anillo de LEDs NeoPixel.
* **Lenguajes y Entornos:** C++ (Arduino IDE), HTML5, CSS3, JavaScript (Web Speech API y Web Serial API).
* **Modelado y Documentación:** Rhino (diseño 3D), esquemáticas de conexiones y registro fotográfico de proceso.
