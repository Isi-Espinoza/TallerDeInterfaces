⚡ DESCRIPCIÓN

CONSOLA - VO2 integra una interfaz física tangible con una interfaz gráfica Web en tiempo real. Combina el control mecánico modular mediante soldadura en PCB Shield (Encargo 1) con un sistema dinámico interactivo guiado por voz a través de la Web Speech API (Encargo 2).

Permite la lectura bidireccional mediante Web Serial API para modular la intensidad de parpadeo, colores y estados de animación en un anillo NeoPixel.

🔧 COMPONENTES Y CONEXIONES DEL SISTEMA
  • Arduino UNO → Placa Central
  • Shield PCB Perfboard → Conexión Modular
  • Fader Deslizante → Pin Analógico A0
  • Potenciómetro Tono → Pin Analógico A2
  • Potenciómetro Brillo → Pin Analógico A4
  • Botón Arcade → Pin Digital 10
  • Botón Reset → Pin Digital 8
  • Anillo NeoPixel 16 → Pin Digital 12
⚙️ FUNCIONAMIENTO Y FLUJO DE TRABAJO
1. ENTRADA: El usuario manipula faders/botones o emite comandos vocales.
2. PROCESAMIENTO: Arduino lee pines analógicos/digitales y Web Speech API procesa el audio.
3. SALIDA Y RESPUESTA: Web Serial API sincroniza el Dashboard y actualiza el anillo NeoPixel.

📌 RESULTADOS OBTENIDOS

Sincronización fluida en tiempo real entre la consola física y el Dashboard. Respuesta inmediata a comandos de voz y actualización contextual de estado.

✓ Luz estática en valor mínimo (0)
✓ Parpadeo máximo configurable (escala 0-1023)
✓ Control dinámico en 16 LEDs NeoPixel
✓ Reconocimiento de voz en tiempo real
✓ Sincronización bidireccional activa
🔌 INPUTS & OUTPUTS DEL CIRCUITO
INPUTS (Entradas): Recibe datos analógicos variables desde el fader y potenciómetros rotativos (0-1023), pulsos digitales de los botones arcade/reset, y comandos de voz interpretados mediante la Web Speech API.
OUTPUTS (Salidas): Envía tramas seriales bidireccionales y gobierna la iluminación RGB dinámica de alta precisión en el anillo NeoPixel de 16 LEDs direccionables.
ESTADOS OPERATIVOS:
ON | Detectando voz / ON | Reset / OFF

ROJO | AZUL | VERDE | ROSADO | AMARILLO | CELESTE | NARANJA | NEGRO
